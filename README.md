# HelloWorld - Backhend to Frontend exercise using the following tools:

- Python and Flask
- Routes
- HTML templates
- Jinja templating
- Static files and images
- Local development servers
- Virtual environments
- Basic project structure

# How it works

-Flask handles python requests and function to connect to URL
-Python defines the routes

# Requirements:

- Python3
- Flask
- Pip

# Library

- Flask
- Flask-SQLAlchemy

# How to Run

  #Terminal
      #Bash
- git clone https://github.com/iceberga91-pixel/HelloWorld.git
- cd Helloworld
- pip install virtualenv
- virtualenv env
- source env/scripts/activate.ps1
- pip install flask flask-sql
- python3 app.py
        
It should give you a promp with a IP similart to: http://***.0.0.1:5000/

Click it or copy it to your browser.

If you find a bug feel free to create a issue of the error ocurred.
